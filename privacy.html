Política de privacidad de Mensajeria-Local

Última actualización: 24 de octubre de 2026

Qué datos se leen. Mensajes de Gmail de las cuentas que el propietario autoriza, con el permiso gmail.readonly (solo lectura). La aplicación no envía, modifica ni borra correos.

Dónde se guardan. Únicamente en el equipo del propietario, en una base de datos local con asunto, remitente y cuerpo cifrados. La clave de cifrado y los tokens de acceso se guardan en el llavero del sistema operativo.

Cómo se procesan. Con modelos de IA que corren localmente. El contenido de los correos no se envía a ningún servicio de IA ni a terceros.

Compartir. No se vende, no se comparte y no se transfiere a nadie. No hay publicidad ni análisis de uso.

Datos de las APIs de Google. El uso y la transferencia a cualquier otra aplicación de la información recibida de las APIs de Google cumplirán con la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos los requisitos de uso limitado.

Revocar y borrar. El acceso se revoca desde la cuenta de Google (Seguridad, Acceso de terceros). Los datos locales se borran eliminando la base de datos de la aplicación.

Contacto. chanchocello@gmail.com

English summary: the app reads Gmail with a read-only scope, stores data only on the owner's computer (encrypted), processes it with local AI, and never sells, shares or transfers it. Use of Google API data follows the Google API Services User Data Policy, including the Limited Use requirements.
